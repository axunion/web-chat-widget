Live backend demo

This page wires the widget to the reference proxy in examples/backend through the real createOpenAISseAdapter — no in-page mock. Start the backend first: 

cd examples/backend
cp .env.example .env   # set OPENAI_API_KEY
pnpm install
pnpm start             # listens on http://localhost:8787

Then open the chat bubble in the corner. See examples/backend/README.md for details. If your .env pins ALLOWED_ORIGIN, it must be http://localhost:4173 (the vite preview origin).

To exercise the non-streaming path instead, swap the adapter for ChatWidget.adapters.createJsonAdapter({ url: "http://localhost:8787/api/chat/json" }).
